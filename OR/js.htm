基本

  • 大文字と小文字を区別する。
  • 文末にはセミコロンを使う(単独の文の場合はあってもなくてもよい)。
  • 変数の型は自動で変わる。
  • 足し算のみでストリング型と数値型の結合を担う。引き算などは文字列が数であれば計算されてしまう。
  • バッククォートで囲んだ文字列に${変数}と書いて足し算を用いてつなぐ必要がなくなる。

変数定義

varは基本の変数、letは宣言した場所のスコープブロック内でのみ定義され、constは定数で後から中身を変更できない。

var a;といったように初期値なしで定義した場合、中身の値はundefinedになる。

var a = 1; let b = 1; const c = 1;

変数の命名規則

  • Unicode文字、_、$が使える。
  • 大文字と小文字を区別。
  • 頭文字に数字は使えない。
  • 予約語は使えない。

ループの途中から脱出

ループを1回スキップ

ラベル

ラベルをつけてbreakやcontinueをどの階層のforやwhileに対するものか指定できる。

egLabel: for(let i=0; i<3; i++) { for(let j=3; j>0; j--) { if(i == j) break egLabel; console.log(i, j); } } // 脱出先はここ /* (i,j) = (0,3), (0,2), (0,1), (1,3), (1,2) */

イテレータ

イテレーターとは

繰り返し処理を実現するための下記特徴を持つオブジェクト。

  • next()メソッドを持つ。
  • next()の戻り値は{value: value, done: done}の形式。
  • valueは次の値、doneはループが継続する場合はfalse、終了する場合はtrueを返す。

実装例

class MyRangeIterator { constructor(n, m) { this.n = n; this.m = m; } next() { return { value: this.n, done: this.n++ > this.m }; } }

反復可能オブジェクトとは

下記の特徴を持つオブジェクト。

  • [Symbol.iterator]()というメソッドを持つ。
  • [Symbol.iterator]()メソッドはイテレーターを返却する。
  • for (...of...)でループ参照することができる。

反復可能オブジェクトの実装例

class MyRange { constructor(n, m) { this.n = n; this.m = m; } [Symbol.iterator]() { return new MyRangeIterator(this.n, this.m); } } for (var n of new MyRange(1, 5)) { console.log(n); // 1, 2, 3, 4, 5 }

ジェネレータ

反復可能オブジェクトを簡単に生成できる仕組み。

  • functionの様にfunctionの後ろにアスタリスクをつけて定義する。
  • yieldまたはyield*を用いて各ループの値を返却する。

ジェネレータの実装例

function* myRange(n, m) { while (n <= m) { yield n++; } } for (var n of myRange(1, 5)) { console.log(n); // => 1, 2, 3, 4, 5 }

import "./module.js"; // module.js からエクスポートされているものすべてをインポートする import { a1, a2 } from "./module.js"; // module.js から a1 と a2 をインポートする import { a1 as b1, a2 as b2 } from "./module.js"; // a1 を b1、a2 を b2 という名前でインポートする import * as mod from "./module.js"; // mod という名前でインポートする (mod.a1, mod.a2, ...)

JSON, CSS

ES2025 からは下記の様に JSON やスタイルシートなども読み込めるようになりました。

import json from "./foo.json" with { type: "json" }; import style from "./style.css" with { type: "ccs" };

CommonJS と ES Modules

モジュールの定義・読み込み方法を提供する主要な仕組み

特徴 COmmonJS (CJS) ES Modules (ESM)
発祥 Node.js (主にサーバサイド) ECMAScript 標準 (ブラウザと Node.js 両方)
ファイル拡張子 .js (通常) .js .mjs .ts (設定による)
インポート方法 require() import
エクスポート方法 module.exports exports.foo export export default
読み込み方式 同期的 (blocking) 非同期的 (非 blocking)
実行順序 実行時に動的に読み込む(遅延実行) 静的に解析(ビルド時に依存関係がわかる)
ツリーシェイキング 不可 可能 (ビルド時に未使用コード除去)

※ ツリーシェイキング: 不要なコードを除去

CJS の例

// math.js function add(a, b) { return a + b; } module.exports = { add }; // app.js const math = require('./math'); console.log(math.add(2, 3));

ESM の例

// math.js export function add(a, b) { return a + b; } // app.js import { add } from './math.js'; console.log(add(2, 3));
